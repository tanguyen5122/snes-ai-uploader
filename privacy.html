Privacy Policy

SNES AI Uploader is a personal tool used only by its owner to publish videos to the owner's own accounts (RetroGamingAI and PlantsHistory) on YouTube, TikTok, Facebook and Instagram, and to read those accounts' view statistics.

What it accesses

It connects to each platform's official API with the owner's permission (including the YouTube Data API, YouTube Analytics API and TikTok's Content Posting API). It reads the owner's own posts, their view statistics, and the public comments left on them (comment text, the commenter's public display name and like counts) so the owner can read and reply to them in one place.

Where it is stored

Sign-in tokens, statistics and comments are stored only on the owner's own computer. They are not shared or sold and are not used for any other purpose. The tool is not offered to other users.

Removing access

  • Google / YouTube: myaccount.google.com/permissions
  • TikTok: Settings and privacy → Security → Apps and services
  • Facebook / Instagram: Settings → Business integrations (Apps and websites)

Removing access stops the tool from reading or posting anything further.

Contact

Questions about this policy can be sent through the contact details on the RetroGamingAI YouTube channel's About page.
